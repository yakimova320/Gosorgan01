## 2. Как работать над Issue: Настя с Claude Code

1. Назначь Issue на себя.
2. Открой Claude Code в папке проекта. Скопируй «Общее начало для Claude» и под ним блок «Текст для Claude» из Issue.
3. Claude покажет план. Понятно: ответь «да». Непонятно: спроси.
4. Когда Claude закончит, пройди «Как проверить».
5. Claude открывает PR. Ссылку отправь Александре.
6. После её «Проверено» нажми «Merge». Issue закроется сам, если в PR стоит верный `Closes #N`.

### Общее начало для Claude

```text
Я Настя, новичок в программировании, у меня дизайнерский опыт. Объясняй по-русски простыми словами.
Прочитай AGENTS.md и workflow/261117/13_TechBriefing_v5_RU.md, затем разделы ТЗ v4, указанные ниже.
Сверь в GitHub номер, название и код задачи. Если они не совпадают с текстом ниже, скажи об этом.
Сначала обнови master из GitHub и создай ветку с именем из задачи.
Покажи план и подожди моего «да». Потом работай самостоятельно.
В конце: pnpm lint, pnpm typecheck, pnpm test, pnpm test:e2e, pnpm build, исправь ошибки, обнови docs/readiness.md.
Сделай коммит, отправь ветку, открой PR с «Closes #N» этой задачи, шагами проверки и скриншотами 390 и 1440 px, если менялся интерфейс.
```

Дмитрий и Геннадий работают как раньше: Дмитрий по шагам без ИИ, Геннадий через Postman и сайт, результат комментарием в Issue.
