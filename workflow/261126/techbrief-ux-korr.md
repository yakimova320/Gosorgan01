# Техбриф UX-KORR 26.11 (web)

Статус: **не выполнять до команды «ausführen»**. Источник: `workflow/261126/ux-ui-korr.md` (пункты 1–9).
Ветка: `ux-korr-2611`, один PR. Только `web/` (+ `content/` для текстов). API, БД и промпты не меняются.

## Общие правила
- Все новые подписи через `t()`, ключ — русский текст; переводы в `web/src/i18n/uk.json` и `de.json`. Тест паритета `i18n.test.ts` должен проходить.
- Ширины проверки: 390, 768, 1280 px. Без горизонтального скролла на 390.
- Доступность: меню и плавающий чат управляются с клавиатуры, `aria-expanded`, `aria-controls`, закрытие по Esc, фокус возвращается на кнопку. Цель клика ≥ 44 px. Контраст текста ≥ 4.5:1.
- Скриншоты до/после: `docs/screenshots/ux-2611/`. Строка в `docs/decisions.md`.

## 8. Кабинет на телефоне — `AppShell` (`components/layout.tsx`)
- Верхняя шапка `.app-topbar`: только логотип. `LanguageSwitcher`, «Спросить», «Главная» убрать оттуда.
- Нижняя панель `.bottom-nav`: Бургер · Konto (`/app`) · большая кнопка камеры (`/app/scan`, как сейчас) · Meine Vorgänge (`/app/cases`) · Profil (`/app/profile`).
- Бургер раскрывает меню снизу слева вверх (sheet над панелью): Startseite, Meine Vorgänge, Verlauf, Fragen (`/app/ask`), Briefe schreiben (`/app/write`), Blog, Glossar (`/glossary`), Profil, выбор языка. Источник пунктов — `MAIN_NAV` (Glossar добавить туда же, тогда он есть и в боковом меню десктопа).

- Десктоп (`.side-nav`) не меняется, только порядок пунктов как в `MAIN_NAV`.
- Подтверждено: «Konto» = обзор кабинета `/app`, «Meine Vorgänge» = список дел `/app/cases`.
