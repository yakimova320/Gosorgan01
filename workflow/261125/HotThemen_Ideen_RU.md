# «Горячие темы»: что взяли из предложения однокурсника и что отложили

Источник: письмо однокурсника (25.11.2026), обсуждение тем в группе русско- и украиноязычных.

## Сделано (KORR 25.11)

Раздел «Горячие темы» на главной (зелёный блок рядом с консультацией) и первой вкладкой в блоге.
Карточки в `content/important/cards.ru.json`, тема `hot`, проверено по источникам 25.11.2026:

| Тема из письма | Карточка |
|---|---|
| Продление ВНЖ и поездки в Украину (вынести отдельно) | `hot-24-extension`, `hot-travel-ukraine` |
| Переход с § 24 на более устойчивый параграф | `hot-switch-permit` |
| Blue Card для специалистов | `hot-blue-card` |
| Подтверждение диплома (отдельно от поиска работы) | `hot-diploma` |
| Поиск работы, выплаты Jobcenter и пособия | `hot-grundsicherung`, `hot-asylblg` |
| Поиск квартиры и оплата аренды | `hot-housing-jobcenter` |
| Языковые курсы | `hot-language` |
| Садик и школа, разница между землями | `hot-kita` |
| Медицина, врачи по языку | `hot-medicine` |

Поправка к письму: «только в двух землях садик бесплатный» верно только для полностью бесплатного садика
(Берлин, Мекленбург-Передняя Померания). Во многих землях бесплатны часы или годы с 3 лет. Так и написано в карточке.

Карточки тоже читает чат-помощник: они добавлены в его контекст вместе с FAQ.

## Отложено (после защиты, нужны решения команды)

1. **Подтемы медицины**: страховка, стоматолог, беременность, рецепты. Писать отдельными карточками.
2. **Поиск специалистов по языку** (врачи, юристы, СТО). Это отдельная функция, а не текст: нужен источник данных
   (116117 Arztsuche для врачей, Rechtsanwaltskammer для юристов), проверка и модерация. Без проверки нельзя:
   риск рекламы и устаревших адресов.
3. **Боты, которые следят за изменениями законов.** Реалистичный вариант: раз в неделю проверять даты и ссылки
   карточек (`checkedAt`, `note`), список RSS официальных источников (Bundesregierung, BAMF, Bundestag hib)
   и задача человеку «перепроверить карточку». Автоматически менять тексты без проверки человеком нельзя.
4. **Кредит на машину и дом с § 24.** Тема финансовая: нужен проверенный источник (Verbraucherzentrale) и
   формулировка без советов «брать или нет».
5. **Разные правила по землям.** В профиле указать землю, карточки с пометкой «зависит от земли» показывать с
   уточнением для этой земли.
6. **Темы для украинского и других языков** (перевод карточек, L07).
