# Иллюстрации

Сюда кладутся акварельные картинки из макета (WebP, прозрачный фон, до 150 КБ):

- worried.webp: тревога, письмо пришло (главная)
- scan.webp: сканировать (загрузка письма)
- talk.webp: вопрос и ответ (разбор письма, «Спросить»)
- relief.webp: облегчение («Готово», кабинет)
- mailbox.webp: пусто (первый вход в кабинет)
- consult.webp: консультация

Пока файла нет, сайт показывает на его месте акварельное пятно.
