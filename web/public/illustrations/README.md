- scan.webp: сканировать (загрузка письма)
- talk.webp: вопрос и ответ (разбор письма, «Спросить»)
- relief.webp: облегчение («Готово», кабинет)
- mailbox.webp: пусто (первый вход в кабинет)
- consult.webp: консультация
- family.webp: тема «Всё о детях» (главная, блок «Блог»)
- living.webp: тема «Жильё» (главная)
- ensurance.webp: тема «Страховки» (главная; имя файла из макета, не менять)
- health.webp: тема «Здоровье» (главная)
