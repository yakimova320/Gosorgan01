# Дизайн Ja!sno: акварельный вариант

Выбран 16.11. Источник: макет «Ja!sno – Mein Bereich (Mobile)», страницы «Акварель · альтернатива» (телефон) и «Акварель · десктоп»: https://claude.ai/artifact/MyZuw5bKgs3y6Q2UUaiu78

Цель: человек с тревожным письмом в руках чувствует облегчение уже на первом экране.

## Палитра

| Имя | Цвет | Где |
|---|---|---|
| Бумага | `#FBF6EE` | фон страниц |
| Оранжевый | `#F25C2A` | главное действие |
| Тёмно-синий | `#1E2A4A` | текст, тёмные блоки |
| Бирюзовый | `#2F8C8A` | ответ, «готово» |
| Коралловый | `#EC7A5C` | вопрос, тревога |
| Горчичный | `#F2B83F` | тепло, подсказка |
| Индиго | `#2E3F72` | тени в иллюстрациях |
| Светлая бирюза | `#DDEFEC` | спокойные блоки |

Вспомогательные: персиковый фон героя `#FBE9DD`, белые карточки `#FFFFFF`, линии `#EFE6DA`, второстепенный текст `#3D4560` и `#5A6072`.

## Шрифты

Rubik 700–800 для заголовков и кнопок, Inter 400–700 для текста.

## Правила

1. Один герой проходит весь путь: тревога, скан, разговор, облегчение.
2. Иллюстрации стоят на мягком акварельном пятне того же тона, что и блок.
3. Интерфейс остаётся чётким: кнопки, текст, отступы без акварели. Акварель только в картинках и пятнах.
4. Бирюзовый означает «ответ» и «готово», оранжевый главное действие, коралловый вопрос.
5. Тексты успокаивают: сначала «без паники», потом шаги и срок.
6. Картинки в WebP с прозрачным фоном, до 150 КБ каждая.

## Иллюстрации

Файлы кладёт Настя в `web/public/illustrations/`. Пока файла нет, сайт показывает на его месте акварельное пятно.

| Файл | Что на картинке | Где стоит |
|---|---|---|
| `worried.webp` | тревога: письмо пришло | главная, первый экран |
| `scan.webp` | действие: сканировать | шаг 1, загрузка письма |
| `talk.webp` | вопрос и ответ | разбор письма, «Спросить» |
| `relief.webp` | облегчение | «Готово», кабинет |
| `mailbox.webp` | пусто | первый вход в кабинет |
| `consult.webp` | консультация | «Найти консультацию» |

## Тексты макета, которые расходятся с решениями

Сайт пишет так, как решено, а не как в макете:

- «Мы напомним заранее», «Напомним за 3 дня»: напоминаний до 03.12 нет. Пишем «Добавьте срок в календарь».
- «Покажем бесплатные консультации рядом с вами»: контактов по городам пока нет. Пишем «Подскажем, куда обратиться».
- «Сфотографировать письмо» на главной без входа: сначала регистрация (решение 16.3).
