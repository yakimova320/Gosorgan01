# AGENTS.md

Проект Ja!sno: помощник для писем немецких ведомств. Команда новичков, код пишет Claude Code у Насти.
Главный документ: workflow/261117/13_TechBriefing_v5_RU.md, где v5 молчит, действует workflow/261116/11_TZ_ClaudeCode_v4_RU.md.
Задачи: GitHub Issues, таблица номеров и тексты в workflow/261117/14_Issues_GitHub_v5_RU.md. Остальное в workflow/ архив.
Объём до защиты: основной путь (вход → PDF или фото → факты → подтверждение → дело → объяснение → один шаблон → копирование), удаление аккаунта, пароль, оценка, запуск. Остальное только после приёмки основного пути.
Дизайн: акварельный вариант, описание в docs/design/README.md.

## Как работать
- Отвечай по-русски простыми словами. Код, имена и коммиты на английском.
- Перед задачей: план, результат, как проверить. Жди «да». Потом работай самостоятельно до результата.
- Одна задача = одна ветка = один PR. Ветка от свежего master, имя из Issue.
- Перед PR зелёные: pnpm lint, pnpm typecheck, pnpm test, pnpm test:e2e, pnpm build.
- Перед PR сверь в GitHub номер, название и код задачи. Номера в старых текстах не используй.
- В PR: Closes #N только для сделанного, шаги проверки для человека, ограничения, скриншоты 390 и 1440 px.
- Не сливай PR, не публикуй, не удаляй данные вне задачи, не подключай платные сервисы.
- Обновляй docs/readiness.md: оболочка / api+demo / api+real / проверено / заблокировано.

## Правила кода
- База только PostgreSQL. Миграции Prisma, SQLite не добавлять.
- Модель только через api/src/llm/LlmService. Ответ проверяется Zod, вызов пишется в LlmCall. Не больше 3 обращений на операцию.
- Цитата обязана быть в тексте письма. Нет данных: null.
- Черновик только из ConfirmedClaim[] (ClaimsService.getConfirmed()), по шаблону в коде.
- Сказанное пользователем: basis USER, status UNCONFIRMED.
- Промпты: api/src/llm/prompts/<имя>.v<N>.md, старые версии не трогать.
- Чужой объект: 404. Пароли, хэши, токены сессий и восстановления не логировать.
- Удаление аккаунта полное: все строки по cabinetId, файлы, LlmCall.
- content/ (FAQ, карточки) пишут люди: тексты не менять.
- Никаких секретов и настоящих данных в репозитории. Только fixtures/letters.
- Каждая задача бэкенда дополняет api/postman/jasno.postman_collection.json.

## NestJS
- ESM: относительные импорты с .js, import.meta.dirname вместо __dirname, Vitest (vi.fn()).
- Внедрение зависимостей с явным @Inject(Класс) в конструкторе: тесты на Vitest не выдают метаданные типов декораторов.
- Проверка входа: Zod через ZodPipe из api/src/common.
- Перед новой библиотекой проверь пакеты @nestjs/* (config, swagger, throttler, schedule, mail). Документация: https://docs.nestjs.com/llms.txt

## Web
- React Router, Redux Toolkit, RTK Query. Свой роутер и fetch-хуки не расширять.
- Данные с сервера только в кэше RTK Query, не копировать в slice. Теги providesTags/invalidatesTags обязательны.
- Выход, истёкшая сессия, удаление аккаунта: api.util.resetApiState() и сброс slices.
- Схемы форм из packages/shared (без Node, Nest, Prisma). Сервер проверяет всё сам.
- Ошибка поля после первого ухода из него, потом при изменении. label, aria-describedby, aria-invalid.
- Основной путь покрыт Playwright (web/e2e) с настоящим API в режиме demo.
